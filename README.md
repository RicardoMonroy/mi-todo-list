# Lista de tareas

Aplicación web simple para gestionar tareas pendientes, construida con HTML, CSS y JS.

## Características

- Agregar nuevas tareas desde un formulario.
- MArcar tareas como completadas (click sobre el texto).
- Eliminar tareas.
- Contaxdor de tareas.

## Tecnologías

- HTML5
- CSS3
- JavaScript (DOM y eventos)

## Como ejecutarlo

1. Clona el repositoprio:
    ```
    git clone https://github.com/RicardoMonroy/mi-todo-list.git
    ```
2. Abre `index.html` en el navegador o usa la extensión **Live Server**
